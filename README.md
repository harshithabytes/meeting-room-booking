\# Bellcorp Meeting Room Booking System



A simple web application for efficient meeting room booking and management.



\## Features



\- View available meeting rooms

\- Book rooms for specific dates and times

\- Prevent overlapping bookings

\- Cancel existing bookings

\- Store booking details in PostgreSQL



\## Technologies Used



\- React.js

\- Node.js

\- Express.js

\- PostgreSQL
